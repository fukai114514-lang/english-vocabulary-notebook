# Content rules

- Update the Phrases library only when the user explicitly requests a phrase-library update. A general request to update the website from recent conversations does not authorize phrase additions.
- Add Word Meanings (polysemy) entries only when the user explicitly requests them.

## Universal Smart Lookup

For every Universal Smart Lookup phase, follow [the architecture and handoff agreement](docs/universal-lookup/handoff.md), including its content, privacy, compatibility, recovery and release boundaries.
