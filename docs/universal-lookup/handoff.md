# TAsLEXICON · Universal Smart Lookup 开发约定

2026-11-25 · Phase 01 架构决策，供所有后续 Phase 使用。网站基线 `17795450973b124b22558f0c7d8bca520b4911ef`。适用于受控开发分支。

## 产品与数据边界

- 目标是在阅读中点击或选中表达内的一个词，即可就地看到整个表达、原句中的含义及单词入口。沿用 TAsLEXICON 品牌、现有阅读器、英文界面和双语学习内容。保留文章、段落与义项 ID、URL、组号、排序和旧锚点。查词范围仍为阅读体验。
- 本地优先。匹配、消歧、词形处理和普通查词离线运行，无服务器、账号或付费 AI 前置条件。不得向外部服务发送网页正文、上下文、页面 URL 或收藏。智能模式中的自动候选只能本地查找。朗读网页来源文本只选择经确认的本机音色；缺失时给出状态。不得增加录音权限。
- 现有 Phrases、Word Meanings、Collocations 和段落标注可只读用于建立索引。不得借生成索引、导入收藏、测试或同步扩写学习栏目的内容。新增 Phrases 或 Word Meanings 须另有用户明确指示。自造例句限测试夹具。
- Phase 01 仅记录审计、规划和基线。进入后续阶段需有该阶段任务授权。非生产分支上的工作不授予修改 main、部署 Pages/Sites、签名分发或提交商店的权限。

## 维护位置与消费

计划在本仓库 `packages/lookup-core/` 唯一维护跨端纯 JS 引擎、数据协议、契约夹具和公开表达索引的构建规范。该目录是下一阶段的目标。现有编辑数据继续在 `content/` 中维护。网站通过本地构建读取同一版本；扩展只消费固定 SHA 的只读快照。另仓的原生工程、私有收藏和专有适配代码不进入公开网站。

每次跨仓升级记录 core SemVer、接口 major、词库 schema/data revision、源 Git SHA、产物与许可清单的 SHA-256。公开源 → 受控构建 → 消费仓候选分支 → 两端同一套夹具 → 锁定后本地打包。禁用运行时 CDN、浮动分支与手工双写。兼容性失败时恢复前一份锁与产物。公共源只接收可公开且出处清楚的内容。

## Phase 02 入口

1. 从上述 SHA 或已复验的后继版本建候选分支。网站运行 `python3 scripts/audit_baseline.py --output /tmp/site-baseline.json` 及 `python3 scripts/test_integration_browser.py`（可指定 `CHROMIUM_PATH`）。
2. 网站基线的第二条命令为 9/10。Collocations 已有 22 条，旧断言仍期望空状态。Inbox 候选 `b175b3311c58f4f99ae992a083c6c120290dabcc` 的同名测试验证真实条数、首条出处和其他空栏目，复跑 10/10。仅移植这项测试修正到后续候选，不合并整个 Inbox 分支。
3. 固定 UTF-16 半开区间、手势锚点、词组范围、释义来源及无结果语义。用已有 VPN 文章 B 段验证点击 rolled 或 back 均得到 rolled back，相邻 rules 仍可单独查词。加入重叠表达、词形、跨行内标签、句界、可编辑区域及断网样例。
4. 每阶段交接记录两个仓库、基线/候选完整 SHA、引擎与数据版本、授权范围、差异文件、命令/环境、实测/模拟/未测、失败复现、回退点、负责人和下一阶段条件。禁止用引擎测试替代 Safari、Firefox 或 Chromium 各品牌的安装验收。保护哈希与生产数据不可为通过测试而刷新。
