## 实施前审查与设计取舍

Python 从原有数据、HTML 片段和共享模板生成静态站点。搜索、语音、阅读器、词典和历史导航由原生 JavaScript 管理。最终页面只加载一份共享样式表。历史模板中的内联样式在构建时已经移除。旧版首页的标题、介绍和搜索堆叠在一条轴上，桌面留下大块未参与排版的空间。四个入口均有图标底色、圆角外框和同级标题。词条列表延用了类似外框。旧版阅读器浮动字号控件与另起一行的段落选择器也占据了正文之前的空间。

借鉴瑞士国际主义排版的几何网格、左齐文字和有依据的非对称关系。标题与目录承担视觉识别，文章段落保留衬线和独立行长。设计背景可见 [Poster House 的 The Swiss Grid 展览](https://posterhouse.org/exhibition/the-swiss-grid/)。

| 设计决策 | 实现及实际效果 |
|---|---|
| 网格 | 首页有效内容宽度达到 864px 时使用十二列，576–863px 使用六列，窄屏使用四轨。桌面标题占前八列，说明和搜索占后四列。目录按编号、名称、说明和数量连续对齐。窄屏目录收窄编号轨，说明和数量排在名称下方。 |
| 比例 | 正文最大宽度 1200px，列间距 12–24px，章节间距 28–56px，继承 4px 间距基准。最近新增占七列，精选阅读占最后四列，中间保留一列。 |
| 字体 | 界面优先使用设备自带 Helvetica Neue、Helvetica 或 Arial，中文回退至苹方、微软雅黑或 Noto Sans CJK SC。无需下载字体。标题固定为两行，字号随容器变化。目录名称用半粗体，序号用等宽数字，正文阅读字号仍由读者控制。 |
| 颜色与组件 | 浅色背景为 #f8f8f5，深色为 #171917。搜索操作、当前导航和键盘焦点使用各主题的红色。顶栏改用实底，词条按细线分行，搜索和词典保留边界与浮层阴影。 |
| 阅读 | 文章标题采用界面无衬线字体，英文段落维持 62ch 上限。返回目录、字号和段落跳转进入可换行的工具栏。保留独立译文、行内查词和原来的键盘焦点方法。 |

### 截图与测量给出的判断

- 在 1440px 宽视口，标题由 56px 增至约 119px。搜索的起点从 x≈299 移至 x≈1025，与标题并列。目录由两排卡片变为四行，名称和数量可以沿各自的列纵向扫描。
- 在 390px 宽视口，标题由 37px 增至约 60px。四个分类合计从约 608px 缩至 494px。标题区增加了约 94px，首个分类的位置因而下移。搜索仍在首屏，阅读和查词保持紧凑。
- 桌面首页让主标题和索引获得更多空间，最近更新的位置随之下移。这是本版可见的取舍。对文章页使用同样夸张的字号会压缩正文，因此文章标题有独立上限。
- 初次复测发现 320px 阅读页的段落选择器越界。限制其父级最大宽度后，七个入口或页面在十三种视口、两个主题下的 182 次候选检查均无整页横向溢出。单词按钮继续跟随正文排版，44px 点击区用于导航及独立控件。

| 可访问性与设备范围 | 已检查可访问名称、标题、导航的当前页、键盘焦点归还和首页独立控件尺寸。浏览器模拟无法代替 iPhone 上的 VoiceOver、软键盘和录音权限，也不能证实 Mac Safari 的实际音色或扬声器输出。 |

基线和候选的首页测量、测试范围和浏览器结果保存在 [results.json](results.json)。候选远端工作流状态应以该提交的 GitHub 检查为准。生产 Pages 工作流监听 main 和手动发布。

## 主要文件

| 路径 | 用途 |
|---|---|
| `content/interface.py` | 首页、导航和阅读工具栏的共享语义结构，保留业务绑定与路由。 |
| `content/search.css` | 在原组件中替换排版、网格、背景、边界和交互状态，并移除旧首页卡片规则。 |
| `dist/search.css`、`dist/*.html` | 重建后的共享样式及 12 个 HTML 文档，每个文档引用正确的内容哈希。 |
| `scripts/measure_homepage.py` | 测量单列索引、两行标题、窄屏上下关系及宽屏左右关系。 |
| `scripts/full-qa.html`、`scripts/reader-qa.html` | 将明暗主题断言的预期颜色更新为候选值。 |
| `migration/reviewed-changes-3.0.json`、`docs/content-review-20261113.json` | 在比对基线内容、ID 和资源后，仅登记新版首页及对应审查清单的哈希。 |

**独立审查结论：可进入正式发布前验收。** 截图能直接辨认首页构图、标题、索引和阅读页层级的改变。建议最终用 iPhone Safari 验证放大字号、VoiceOver 朗读顺序、软键盘弹出及真人录音，并用 Mac Safari 验证系统字体与声音。正式合并和发布由项目所有者单独授权。
