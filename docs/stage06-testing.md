- 全部 137 组辨析和 75 个多义词，在两种宽度逐项展开/关闭，共 424 次检查。
- 全部 5 篇独立文章，四种视口 × 浅/深/系统主题，共 60 组文章页面检查。
- 每篇英文段落首末词查词、切换与关闭，共 1,464 次查词检查；含面板位置、阅读位置、关闭焦点和翻译显示。
- 共 6,993 项断言通过；被测布局未发现横向溢出，交互错误监听无异常。浏览器日志中未发现应用错误（忽略扩展自身错误）。

## 失败项目及修复记录

| 严重程度 | 浏览器复现 | 修复与复验 |
| --- | --- | --- |
| P2 | 1024px 桌面浮层右缘为 1012px，而内容视口宽度为 1009px，越界 3px | 定位使用 documentElement.clientWidth 并限制 maxWidth；全文章/多视口浮层边界断言通过 |
| P2 | 长段落按 End 后焦点矩形 top=844.5、bottom=880.5，超出 568px 视口 | 仅显式方向键/Home/End 选词允许浏览器滚动以显示目标；打开/关闭查词仍保持位置；实际按键复验通过 |
| 环境限制 | check_deployment.py 请求命令行本机 127.0.0.1:4173 被拒绝 | 浏览器与执行器网络隔离；改用浏览器资源测试。没有将此项误报为生产站点故障 |
| 预览差异 | HTML 原始哈希与构建文件不一致 | 证实为预览自动注入；归一化检查通过，生产校验脚本未放宽 |
| 环境限制 | 实际朗读无法发声 | 设备语音不可用，错误处理通过；真实声音仍待设备验证 |

仅修改阅读器的两个缺陷。未新增学习功能，未重做视觉设计。CI 统一调用完整离线门禁并上传报告，避免遗漏新增的链接、UI 隔离和对比度检查。
